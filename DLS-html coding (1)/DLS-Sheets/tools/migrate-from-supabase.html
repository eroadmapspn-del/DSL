Copy existing data from Supabase into the Google Sheet

Run this once, from the deployed Netlify site (or any page that loads config.js + sheets-client.js). It only reads from Supabase and adds rows to the sheet – nothing in Supabase is changed. Rows keep their original id and user_id, so first make sure each person's row in the Credentials sheet has the same id as their old Supabase user id (see README, “Migrating old data”).
