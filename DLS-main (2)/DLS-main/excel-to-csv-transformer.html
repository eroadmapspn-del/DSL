📊 Excel to CSV Transformer

Transform Excel bills to CSV format for approved_bills table import

🔄 Processing Rules:

  • All bills → Transformed to CSV for approved_bills table import
  • Status = "Edited" → Included with status "edited" (preserves original payment data)
  • Status = "Delivered" → Transformed with status "approved"
  • Status = "Cancelled/Returned" → Transformed with status preserved

📋 Column Mappings:

  • Delivery Method → payment_method (Cash/Cheque/UPI/Credit/NEFT)
  • Received Amount → Sum of Cash Received + Cheque Amount + UPI Amount
  • Receipt Number:
    • Cash → Cash Receipt Number
    • Cheque → Cheque Number
    • UPI → UPI Receipt Number
  • Sector → Sector column from Excel
  • Timestamp → created_at

📥 Output: Download CSV file and import to Supabase → approved_bills table.
