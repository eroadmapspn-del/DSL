Purchase Upload Test File Generator

Instructions:

  1. Click "Generate Test CSV File" to download a test file
  2. Open the downloaded CSV file in Excel
  3. Save it as an Excel file (.xlsx format)
  4. Use the Excel file to test the Purchase Section file upload in the main application
  5. Navigate to: PURCHASE → Purchase Base File → Click Upload button

Generate Test Data

This will create a CSV file with the correct format for testing:

Retailer Name,Due Days

File Format Requirements

Column Headers (Case-insensitive):

  • Retailer Name - Name of the retailer
  • Due Days - Number of days (integer)

Testing Steps

To test the file upload:

  1. Generate and download the test CSV file above
  2. Open it in Excel and save as .xlsx format
  3. Go to the main application (supply.html)
  4. Click on "PURCHASE" tab at the top
  5. Click on "Purchase Base File" in the sub-navigation
  6. Click the "Upload" button and select your Excel file
  7. You should see a success toast message
  8. Click the "View" button to see the uploaded data in a table
